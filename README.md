# Reader for X

_Not affiliated with X Corp._

Reader for X is a Chrome extension that gives X (Twitter) a clean, distraction-free reading layout.

- **Reader Mode:** individual posts, threads and X Articles open as a centered, article-style page, without sidebars and recommendations.
- **Timeline Mode:** your Home feed, profiles and search use the whole screen instead of a narrow column.
- **Simple settings:** turn each mode on or off, fill the window or pick a width, hide the sidebar or left navigation, and choose X's typography or a serif reading face. Changes apply instantly.

Everything runs locally in your browser. Reader for X collects no data, makes no network requests, and only asks for the `storage` permission to save your settings. See the [privacy policy](PRIVACY.md).

## Install

**[Add to Chrome — Chrome Web Store](https://chromewebstore.google.com/detail/reader-for-x/nnnobogbdimakckdfgiilbgeemgjjnbe)**

After installing, refresh any open X tabs. Click the toolbar icon to change settings.

## Support

Found a problem, or does a page look wrong? X updates its website often, and the layout may need adjusting after a change.

[Open an issue](../../issues/new/choose) and include:

- the page URL type (post, Home, profile, search…)
- a screenshot
- your Chrome version (`chrome://version`)

Please don't include private information in issues. Issues are public.
